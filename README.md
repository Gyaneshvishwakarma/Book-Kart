# 📚 BookKart – Online Book Selling Website

BookKart is a full-stack web application built using **Next.js**, **MySQL**, and **JavaScript**.  
It allows users to **buy, sell, and manage books online**.  
The platform includes admin and user dashboards, book listings, and database management — all in one modern, responsive interface.

---

## 🚀 Features

### 🧑‍💻 User Features
- 🔐 User authentication (login/register system)
- 📚 Browse all listed books
- 🔍 Search books by title, author, or category
- 🛒 Add new books for sale
- 📝 Edit or delete own listings
- 💬 Contact sellers for purchase

### 🧑‍🏫 Admin Features
- 📊 Admin dashboard to view total users and books
- 🗑️ Delete any inappropriate or duplicate listings
- 🧾 Manage book database easily through the panel
